The three variants

Each surface renders A, B, and C — the floating bar at the bottom of every page flips between them. Keys 1 / 2 / 3 also flip.

variant nav density today comp.
A Palette-primary (⌘K is discovery; visible nav is minimal) Comfortable Single-column relevant-now stack
B Visible-rail (every section up top) Comfortable Two-column primary + side rail
C Hybrid (3 grouped dropdowns + visible ⌘K hint) Compact Four-card grid

How to view

From the repo root: python3 -m http.server 8765, then open localhost:8765/prototypes/2026-baseline/. Pages pull the real static/css/tokens.css + static/css/main.css; the amber + dark surface you see is what the live app would look like with the proposed structural change.
